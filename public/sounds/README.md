# Sound Assets — Required Files

Place the following audio files (MP3, 96kbps min) in this `/public/sounds/` directory:

| File | Purpose | Notes |
|------|---------|-------|
| `neural-hum.mp3` | Ambient neural hum on load | Looping, low-frequency hum ~5–10s |
| `scramble.mp3` | Plays during brand name glitch decode | Short burst, ~0.8s |
| `click.mp3` | Plays on "Explore" CTA click | Short click/tick, ~0.2s |

**Audio is muted by default.**  
The user must click the SFX toggle (top-right corner) to enable sounds.

Free sound sources:
- https://freesound.org
- https://mixkit.co/free-sound-effects/
- https://www.zapsplat.com
